## Python comme calculatrice

La première chose que nous vous apprendrons est d'_utiliser Python comme une calculatrice scientifique_.
La syntaxe est relativement similaire à ce que vous entreriez sur votre calculatrice,
comme le montre l'exemple suivant:

:::example

```python run
(3 + 5) * 2
```

:::

Nous vous encourageons à modifier l'exemple ci-dessus pour vous familiariser avec la syntaxe.

- Pour les opérations arithmétiques,

  - `+` correspond à l'_addition_
  - `-` correspond à la _soustraction_
  - `*` correspond à la _multiplication_
  - `/` correspond à la _division_
  - `**` correspond à l'_exponentiation_. Par exemple, `2 ** 3` correspond à $2^3 = 8$.

- On utilise le point `.` comme **séparateur décimal**
  (au lieu de la virgule).

- Pour un nombre complexe, on utilise `j` pour représenter l'unité imaginaire.
  Par exemple, `1 + 2j` correspond à $1 + 2i$.
  Le `j` doit absolument suivre un nombre sans espace,
  ce qui signifie que $i$ est `1j` en Python.

## La bibliothèque `math`

Qu'en est-il de la racine carré, des fonctions trigonométriques, exponentielles et logarithmiques?
Nous allons pour cela utiliser la bibliothèque `math` de Python,
qui contient de nombreuses fonctions mathématiques utiles,
telles que:

- `sqrt` (la racine carrée ou _**sq**uare **r**oo**t**_)
- `sin`, `cos`, `tan`
- `exp`, `log`

Comme en mathématiques,
une fonction est appliquée à un _argument_ entre parenthèses.

{tex`%
\underbrace{\mathrm{sqrt}}_{\text{fonction}}(67) \rightarrow \sqrt{67}
`}

```python run
# On importe la fonction sqrt de la bibliothèque math
from math import sqrt

# On l'utilise ensuite pour notre calcul
sqrt(2)
```

Par défaut, `log` est le logarithme népérien (base $e$),
mais il est possible de calculer le logarithme d'une autre base en utilisant un second argument.

:::example

Pour calculer $\log_{10}(67)$,
on procède comme suit:

```python run
from math import log
log(67, 10)
```

:::

:::remark
Pour importer plusieurs fonctions d'une bibliothèque, on peut les séparer par des virgules:

```python run
from math import sqrt, log
log(sqrt(73))
```

Il est également possible d'importer toute la bibliothèque

```python run
from math import *
log(sqrt(73))
```

:::

## Fonctions à une variable

Pour définir une _fonction_,
on utilise le mot clé `def`,
suivi du _nom de la fonction_,
de ses _paramètres_ éventuels entre parenthèses,
et d'un `:` à la fin de la ligne.

Les lignes suivantes doivent être indentées (décalées vers la droite) de 4 espaces
pour indiquer qu'elles font partie de la fonction.

```python
def nom_de_la_function(x):
    return x
```

:::example

Pour définir la fonction $f(x) = x^2$ en Python, on procède comme suit:

```python
def f(x):
    return x**2
```

Notez la présence du `:` à la fin de la première ligne

:::
