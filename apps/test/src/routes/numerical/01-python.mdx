# Introduction à Python

L'objectif de cette activité est de vous guider dans vos premiers pas en programmation.
N'ayez pas peur si vous n'avez jamais programmé auparavant,
nous commencerons de zéro.

Programmer,
c'est _écrire des instructions à un ordinateur_ (le _code_)
dans un langage qu'il peut comprendre.
L'ordinateur se chargera ensuite d'exécuter ces instructions pour nous,
et nous informera du résultat éventuel.
Dans cette activité, nous utiliserons le langage de programmation Python,
qui est très populaire et utilisé dans de nombreux domaines scientifiques.

Notre premier programme sera très simple,
il se contentera d'afficher un message.
Nous vous ferons souvent apprendre en modifiant un code existant,

## Python comme calculatrice scientifique

Qu'en est-il de la racine carré, des fonctions trigonométriques, exponentielles et logarithmiques?
Nous allons pour cela utiliser la bibliothèque `math` de Python,
qui contient de nombreux outils mathématiques utiles,
telles que:

- les fonctions:
  - racine carrée (`sqrt`)
  - trigonométriques `sin`, `cos`, `tan`
  - cyclométriques $\arcsin$ (`asin`), $\arccos$ (`acos`), $\arctan$ (`atan`)
  - exponentielles (`exp`) et logarithmes (`log`)
- les constantes $\pi$ (`pi`) et $e$ (`e`).

Par défaut, ces fonctions ne sont **pas disponibles** dans l'environnement Python.
Nous devons les **importer**,
et il existe plusieurs façons de le faire.

:::example

Supposons que vous souhaitiez calculer la racine carrée de $2$ et la valeur de $\pi$.

|                      | Import simple  | Import spécifique           | Import étoile        |
| -------------------- | -------------- | --------------------------- | -------------------- |
| Import               | `import math`  | `from math import sqrt, pi` | `from math import *` |
| Calcul de $\sqrt{2}$ | `math.sqrt(2)` | `sqrt(2)`                   | `sqrt(2)`            |
| Valeur de $\pi$      | `math.pi`      | `pi`                        | `pi`                 |

:::

:::remark
L'import simple est le plus _explicite_ et est préféré dans les codes professionels.
L'import étoilé est le plus concis,
peut porter à confusion,
mais est acceptable pour des calculs rapides et simples.

À titre d'exemple,
il existe plusieurs implémentations de la fonction racine carrée:
`sympy.sqrt`, `numpy.sqrt`, `math.sqrt`, etc.
Avec l'import simple, le choix est _délibéré_ et _explicite_ à chaque appel.
:::

```python run
# On importe la fonction sqrt de la bibliothèque math
from math import sqrt

# On l'utilise ensuite pour notre calcul
sqrt(2)
```

Par défaut, `log` est le logarithme népérien (base $e$),
mais il est possible de calculer le logarithme d'une autre base en utilisant un second argument.

:::example

Pour calculer $\log_{10}(67)$,
on procède comme suit:

```python run
from math import log
log(67, 10)
```

:::

| Opération            | Exemple        | Code Python       |
| -------------------- | -------------- | ----------------- |
| Racine carrée        | $\sqrt{7}$     | `math.sqrt(7)`    |
| Racine cubique       | $\sqrt[3]{7}$  | `7 ** (1 / 3)`    |

| Logarithme népérien  | $\ln(7)$       | `math.log(7)`     |
| Logarithme base $10$ | $\log_{10}(7)$ | `math.log(7, 10)` |

## Variables

Les variables permettent de stocker des valeurs pour les réutiliser plus tard.
Elles jouent un rôle important pour rendre le code plus lisible et plus facile à maintenir.

:::example
Calculez la surface d'un cylindre de rayon $2$ et de hauteur $3$,
en utilisant préalablement les variables `r` et `h` pour le rayon et la hauteur.

```python run
from math import pi

r = 2
h = 3
S = 2 * pi * r**2 + 2 * pi * r * h
S
```

L'avantage de l'utilisation de variables
est qu'il est possible de modifier les valeurs de `r` et `h`
pour calculer la surface avec d'autres données,
sans avoir à réécrire tout le calcul.
:::

## Le calcul vectoriel avec `numpy`

### Listes de nombres

Pour créer une liste de nombres,
on l'écrit entre crochets `[]`,
et on sépare les éléments par des virgules `,`.

```python
[1, 2, 3, 4, 5]
```

### Vecteurs

Pour créer un vecteur,
on peut utiliser la bibliothèque `numpy`,
qui est spécalisée dans le calcul scientifique.

:::example
Pour créer le vecteur $\vec v = (1, 2, 3)$,
on écrit:

```python run
import numpy as np
v = np.array([1, 2, 3])
```

:::

Pour l'addition et la multiplication scalaire de vecteurs,
il suffit d'utiliser les opérateurs `+` et `*` comme pour les nombres.

:::example
Si $\vec v = (1, 2, 3)$ et $\vec w = (4, 5, 6)$,
calcule $2 \vec v + 3 \vec w$.

```python run
import numpy as np
v = np.array([1, 2, 3])
w = np.array([4, 5, 6])
2 * v + 3 * w
```

:::

### Produit scalaire

```python run
import numpy as np
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
np.dot(a, b)
```

### Produit vectoriel

```python run
import numpy as np
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
np.cross(a, b)
```
