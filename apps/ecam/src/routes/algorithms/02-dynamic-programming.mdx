# Memoization

## A cache, by hand

```python
memo = {}

def fib(n):
    if n in memo:
        return memo[n]
    result = n if n < 2 else fib(n - 1) + fib(n - 2)
    memo[n] = result
    return result
```

## functools.cache

```python
from functools import cache

@cache
def fib(n):
    if n < 2:
        return n
```

# Dynamic programming

## The idea

:::incremental

- Smaller subproblems, which **overlap**.
- Each solved **once**, then remembered: **memoization**.
- Top down: a recursive function with `@cache`.

:::

# Rod cutting

## Rod cutting

Cut a rod of length $n$ to sell its pieces, a piece of length $i$ for $p_i$.

| $i$   | 1   | 2   | 3   | 4   | 5   | 6   | 7   | 8   |
| ----- | --- | --- | --- | --- | --- | --- | --- | --- |
| $p_i$ | 1   | 5   | 8   | 9   | 10  | 17  | 17  | 20  |

<Exercise.Questions />

## Solution

```python
from functools import cache

def cut_rod(prices, n):
    @cache
    def best(k):
        if k == 0:
            return 0
        return max(prices[i - 1] + best(k - i) for i in range(1, k + 1))
    return best(n)
```

## Bonus: where to cut?

```python
def cut_pieces(prices, n):
    @cache
    def best(k):
        if k == 0:
            return 0, None
        return max((prices[i - 1] + best(k - i)[0], i) for i in range(1, k + 1))
    pieces = []
    while n > 0:
        pieces.append(best(n)[1])
        n -= pieces[-1]
    return pieces
```
