## Prérequis

1. Installez [Git](https://git-scm.com/),
   un logiciel de contrôle de version.

2. Installez [Docker Desktop](https://www.docker.com/products/docker-desktop/)

3. Installer [Visual Studio Code](https://code.visualstudio.com/)
   ou un autre éditeur de texte de votre choix.

## Lancer le projet

1. Ouvrez le projet dans Visual Studio Code avec le containeur de développement.

2. Dans un terminal du containeur, exécutez la commande

   ```bash
   bun dev
   ```
