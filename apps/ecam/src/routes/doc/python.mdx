# Créer des exercices Python

Dans un exercice Python, l'étudiant·e écrit du code directement dans la page,
l'exécute dans son navigateur,
et la plateforme le corrige en vérifiant une liste de tests.

## Un premier exercice

```tsx
import { PythonCode } from '@learning/exercises/python/Code'

;<PythonCode
  id="carre"
  prompt={
    <p>
      Définissez une fonction <code>carre</code> qui renvoie le carré d'un nombre.
    </p>
  }
  initialCode={'def carre(x):\n    '}
  tests={(expect) => ({
    'carre(3) vaut 9': expect.with('carre(3)').toReturn(9),
    'carre(-2) vaut 4': expect.with('carre(-2)').toReturn(4),
    'carre(0.5) vaut 0.25': expect.with('carre(0.5)').toReturn(0.25),
  })}
/>
```

<Demo.Square />

Chaque test a une description, affichée à l'étudiant·e avec une coche ou une croix,
et une vérification écrite avec `expect`.
La réponse est juste quand tous les tests passent.

| Attribut      | Rôle                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------ |
| `prompt`      | L'énoncé                                                                                   |
| `tests`       | Les tests, écrits avec `expect`                                                            |
| `initialCode` | Le code affiché au départ ; `\n` passe à la ligne                                          |
| `math`        | Ajoute NumPy et les nombres duaux, et affiche les graphiques Matplotlib                    |
| `mode`        | `'manual'` n'exécute le code que lorsque l'étudiant·e clique, utile pour les calculs longs |

## Les vérifications

`expect` exécute le code de l'étudiant·e, puis vérifie son résultat.
Le **résultat** est la valeur de la dernière ligne du code,
comme dans une calculatrice ;
ce qui est **affiché** est ce qu'écrit `print`.

| Vérification                                                      | Vrai si…                                                                     |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `expect.result().toBe(42)`                                        | Le résultat vaut `42`                                                        |
| `expect.result().toBe(0.1 * 0.1, 0)`                              | Le résultat est exactement le nombre que Python calcule pour $0.1 \cdot 0.1$ |
| `expect.result().toEqualThatOf('import numpy as np\nnp.sqrt(2)')` | Le résultat est celui du code donné                                          |
| `expect.result().toEqualThatOf(code, 1e-6)`                       | Le résultat est celui du code donné, à `1e-6` près                           |
| `expect.with('f(2)').toReturn(4)`                                 | Après le code de l'étudiant·e, `f(2)` vaut `4`                               |
| `expect.output().toEqualThatOf('2 * 21')`                         | Le résultat, ou ce qui est affiché, est celui du code donné                  |
| `expect.stdout().toBe('Bonjour')`                                 | Le code affiche `Bonjour`                                                    |
| `expect.stdout().toMatch(/bonjour/i)`                             | Ce qui est affiché contient « bonjour », en majuscules ou non                |
| `expect.code.toMatch(/for /)`                                     | Le code contient une boucle `for`                                            |
| `expect.code.not.toMatch(/linalg/)`                               | Le code n'utilise pas `linalg`                                               |
| `expect.not().toError()`                                          | Le code s'exécute sans erreur                                                |

`output()` accepte la réponse renvoyée comme la réponse affichée,
même après d'autres lignes :
les étudiant·es affichent souvent leur réponse avec `print` au lieu de la donner en dernière ligne.
Préférez-le à `result()`,
sauf si l'exercice porte justement sur la valeur renvoyée.

Les nombres sont comparés à une erreur relative de `1e-9` près, comme le fait `math.isclose` en Python :
`0.1 + 0.2` vaut donc `0.3`.
Une erreur donnée en second argument est absolue,
comme dans `toBe(3.14, 0.01)` ou `toEqualThatOf(code, 1e-6)` ;
une erreur de `0` exige le nombre exact,
par exemple pour montrer que `0.1 * 0.1` ne vaut pas `0.01` en Python.

`toEqualThatOf` est le plus pratique :
au lieu de calculer la réponse vous-même, écrivez le code qui la calcule.
Le texte entre barres obliques, comme `/for /`, est un motif de recherche :
`i` à la fin ignore les majuscules.

## Les graphiques

Avec `math`, les vérifications suivantes portent sur le graphique Matplotlib de l'étudiant·e :

| Vérification                                  | Vrai si…                                                  |
| --------------------------------------------- | --------------------------------------------------------- |
| `expect.matplotlib.plot('np.sin(x)', -3, 3)`  | Le graphique contient la courbe de $\sin x$ sur $[-3, 3]$ |
| `expect.matplotlib.xLabel().toMatch(/x/)`     | L'axe horizontal a un nom qui contient « x »              |
| `expect.matplotlib.yLabel().toMatch(/y/)`     | L'axe vertical a un nom qui contient « y »                |
| `expect.matplotlib.title().toMatch(/sinus/i)` | Le titre contient « sinus »                               |
| `expect.matplotlib.grid()`                    | La grille est affichée                                    |
| `expect.matplotlib.lineCount().toBe(3)`       | Le graphique contient $3$ courbes                         |
| `expect.matplotlib.sameScale().toBe(true)`    | Les deux axes ont la même échelle                         |

```tsx
<PythonCode
  id="sinus"
  math
  prompt={<p>Tracez le graphe de la fonction sinus sur [-3, 3], et nommez les axes.</p>}
  tests={(expect) => ({
    'La courbe est tracée': expect.matplotlib.plot('np.sin(x)', -3, 3),
    "L'axe x est nommé": expect.matplotlib.xLabel().toMatch(/x/),
    "L'axe y est nommé": expect.matplotlib.yLabel().toMatch(/y/),
  })}
/>
```

## Demander à l'assistant

:::info[Un exemple de demande]
Décrivez ce que le code doit faire,
puis les cas sur lesquels le tester, y compris les cas limites,
et ce que le code ne doit pas utiliser.

> Crée un exercice Python où l'étudiant·e définit une fonction `moyenne(liste)`.
> Teste-la sur [2, 4, 6], sur [5] et sur [-1, 1].
> Vérifie que le code n'utilise ni `statistics` ni `numpy`.

Écrivez ensuite une solution juste, puis une solution fausse,
pour vérifier que les tests font la différence.
:::

:::remark[Les anciens exercices]
Certains anciens exercices utilisent `Matplotlib`, `PythonFunction` ou une liste de tests `{ desc, test, check }`.
Ces formes sont dépréciées :
les nouveaux exercices utilisent `PythonCode` et `expect`.
:::
