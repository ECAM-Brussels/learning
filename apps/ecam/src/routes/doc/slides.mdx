# Les présentations

`Deck` affiche une présentation [reveal.js](https://revealjs.com) dans une page,
avec l'apparence du thème Beamer _Metropolis_.

<Example.Demo />

Cliquez sur la présentation pour la piloter au clavier :

- les flèches passent d'un slide à l'autre ;
- `F` affiche la présentation en plein écran, `Échap` montre une vue d'ensemble ;
- `S` ouvre la vue présentateur, avec les notes, si le plugin de notes est chargé.

## Les slides

Une présentation est un `Deck` dont les enfants sont des slides :

| Composant       | Rôle                                                               |
| --------------- | ------------------------------------------------------------------ |
| `Deck.Title`    | Le titre, avec un sous-titre, l'auteur·e, l'institution et la date |
| `Deck.Section`  | Le début d'une partie, avec une barre de progression               |
| `Deck.Slide`    | Un slide, avec un titre facultatif                                 |
| `Deck.Standout` | Un slide sombre pour une phrase marquante                          |
| `Deck.Stack`    | Des slides empilés verticalement                                   |

Dans un slide, `Deck.Fragment` fait apparaître son contenu au fil de la présentation,
`Deck.Alert` met un mot en évidence
et `Deck.Notes` contient les notes du présentateur ou de la présentatrice.

```tsx
<Deck>
  <Deck.Title title="Les dérivées" author="Prénom Nom" />
  <Deck.Section title="Définition" />
  <Deck.Slide title="Taux d'accroissement">
    <p>
      La dérivée de <Deck.Alert>f</Deck.Alert> en {tex`a`} est…
    </p>
    <ul>
      <Deck.Fragment as="li">la pente de la tangente</Deck.Fragment>
    </ul>
  </Deck.Slide>
  <Deck.Standout>Des questions ?</Deck.Standout>
</Deck>
```

Comme pour les autres composants, la présentation va dans un fichier `*.deck.tsx` voisin de la page,
et la page l'importe : `import * as Slides from './cours.deck'` puis `<Slides.Derivees />`.

## Configuration

`config` reçoit les [options de reveal.js](https://revealjs.com/config/),
par exemple `config={{ transition: 'slide' }}`,
et `plugins` ses plugins, comme `reveal.js/plugin/notes`.
`class` change la taille de la présentation, en 16:9 sur toute la largeur par défaut.
Les couleurs sont les variables CSS `--m-dark`, `--m-accent` et `--m-light`.
