# Manipuler des expressions mathématiques

Pour corriger une réponse ou écrire un exercice,
la plateforme transforme le LaTeX en **expression** que le calcul formel sait manipuler,
comme on le ferait à la main.
Cette page présente les deux fonctions qui le permettent :
`expr`, qui crée une expression, et `tex`, qui l'affiche.

## Créer une expression

`expr` lit une formule écrite en LaTeX :

```ts
import { expr } from '@learning/core'

const f = expr('x^2 - 5x + 6')
```

Dans un exercice, les données et les réponses déclarées comme expressions le sont déjà :
`attempt` dans `grade={(attempt) => …}` en est une, par exemple.

## Transformer une expression

Ces opérations renvoient une nouvelle expression, qu'on peut transformer à son tour :

| Opération                | Résultat                                                       |
| ------------------------ | -------------------------------------------------------------- |
| `f.expand()`             | La forme développée                                            |
| `f.factor()`             | La forme factorisée                                            |
| `f.simplify()`           | La forme simplifiée                                            |
| `f.diff()`               | La dérivée par rapport à $x$ ; `f.diff('t')` par rapport à $t$ |
| `f.diff('x', 2)`         | La valeur de la dérivée en $x = 2$                             |
| `f.integrate('x')`       | Une primitive                                                  |
| `f.integrate('x', 0, 1)` | L'intégrale de $0$ à $1$                                       |
| `f.subs({ x: 2 })`       | L'expression où $x$ est remplacé par $2$                       |
| `f.taylor('x', 0, 3)`    | Le développement de Taylor d'ordre $3$ en $0$                  |
| `f.abs()`                | La valeur absolue                                              |
| `f.N()`                  | Une valeur numérique approchée                                 |

Par exemple, `expr('x^3').diff().subs({ x: 2 })` calcule la dérivée de $x^3$ en $2$, c'est-à-dire $12$.

## Poser une question sur une expression

Ces questions sont envoyées au calcul formel,
et leur réponse arrive un instant plus tard :
c'est ce qu'il faut pour corriger une réponse.

| Question                         | Vrai si…                                  |
| -------------------------------- | ----------------------------------------- |
| `f.isEqual(g)`                   | $f$ et $g$ sont mathématiquement égales   |
| `f.isEqual(g, 0.01)`             | $f$ et $g$ diffèrent de moins de $0.01$   |
| `f.isFactored()`                 | $f$ est sous forme factorisée             |
| `f.isExpanded()`                 | $f$ est sous forme développée             |
| `f.checkRoot(2)`                 | $2$ est une racine de $f$                 |
| `f.leq(g)`, `f.lt(g)`            | $f \leq g$, $f < g$ (aussi `geq` et `gt`) |
| `expr('2^{10} > 1000').isTrue()` | L'égalité ou l'inégalité est vraie        |

`isEqual` compare des valeurs, pas des écritures :
pour exiger aussi une forme, combinez deux questions.
L'exercice `Factor` vérifie ainsi que la réponse est égale au polynôme **et** qu'elle est factorisée.

## Afficher une expression

`tex` affiche une formule LaTeX.
Entre `${` et `}`, on peut y insérer une expression, qui sera écrite en LaTeX à son tour :

```mdx
import { expr, tex } from '@learning/core'

{tex`\int_0^1 x^2 \, \mathrm{d}x = ${expr('x^2').integrate('x', 0, 1)}`}
```

affiche

{tex.display`\int_0^1 x^2 \, \mathrm{d}x = ${expr('x^2').integrate('x', 0, 1)}`}

Le résultat $\frac 1 3$ n'est écrit nulle part : il a été calculé.
De même,

{tex.display`(x - 2)(x - 3) = ${expr('(x - 2)(x - 3)').expand()}`}

## Pourquoi pas une calculatrice ?

Un ordinateur calcule d'habitude avec des nombres à virgule, arrondis à environ $16$ chiffres :
il trouverait que $0.1 + 0.2$ ne vaut pas $0.3$.
Le calcul formel travaille, comme vous, avec des fractions exactes, des racines et des symboles :
c'est pourquoi il peut dire que deux réponses écrites différemment sont égales.

La plateforme en utilise deux :
[Compute Engine](https://mathlive.io/compute-engine/), qui tourne dans le navigateur de l'étudiant·e et répond tout de suite,
et [SymPy](https://www.sympy.org/), sur le serveur, pour les questions plus difficiles.
Vous n'avez pas à choisir : la plateforme s'en charge.
