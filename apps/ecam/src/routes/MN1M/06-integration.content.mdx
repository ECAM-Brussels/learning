# Introduction

De nombreuses applications scientifiques et de l'ingénierie se réduisent au **calcul d'aire** sous une courbe.
Nous commencerons par étudier la notion de **moyenne** et un exemple de cinématique.

Nous introduirons ensuite trois méthodes numériques communes pour calculer des intégrales:
la méthode du **point milieu**, la **règle du trapèze** et la **règle de Simpson**.

## Partitions d'un intervalle

Nous appellerons une _partition_ d'un intervalle $[a, b]$ en $n$ sous-intervalles
la donnée de $n$ nombres {tex`x_0, x_1, x_2, \ldots, x_{n - 1}`} tels que
{tex.display`a = x_0 < x_1 < x_2 < \cdots < x_{n - 1} < b`}
et $[x_0, x_1]$, $[x_1, x_2]$, $\ldots$, {tex`[x_{n-1}, b]`} sont des intervalles de même longueur,
que l'on dénotera {tex`\mathrm{d}x`} (appelé **pas** de la partition).
Regardez bien l'animation ci-dessous pour vous familiariser avec cette notion.

<Exercise.Partition />

Remarquez que les nombres {tex`x_0, x_1, \dots, x_{n - 1}`} sont les **bornes gauches** de chacun des sous-intervalles.

En Python,
une partition de $[a, b]$ en $n$ sous-intervalles et son pas {tex`\mathrm{d}x`}
s'obtiennent de la manière suivante:

```python
import numpy as np

x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)
```

:::remark

- `endpoint=False` exclut $b$, comme demandé par la définition de partition.
- `retstep=True` pour `return step` (_retourne le pas_) permet d'avoir aussi la valeur de {tex`\mathrm{d}x`}.

:::

| Concept                    | Code Python                                                  | Commentaire                            |
| -------------------------- | ------------------------------------------------------------ | -------------------------------------- |
| Partition                  | `x = np.linspace(a, b, n, endpoint=False)`                   | Donne les $n$ points de la partition   |
| Partition avec pas         | `x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)` | Donne également le pas `dx`            |
| Vecteur des bornes gauches | `x`                                                          | Borne gauche de chaque sous-intervalle |
| Vecteur des points milieux | `x_m = x + dx / 2`                                           | Point milieu de chaque sous-intervalle |
| Vecteur des bornes droites | `x_r = x + dx`                                               | Borne droite de chaque sous-intervalle |

:::example[Partition d'un intervalle]

Regardons une partition de l'intervalle $[0, 1]$ en $10$ sous-intervalles.
On s'attend à ce que les dix sous-intervalles soient $[0, 0.1]$, $[0.1, 0.2]$, $\ldots$, $[0.9, 1]$.

```python run
import numpy as np

x, dx = np.linspace(0, 1, 10, endpoint=False, retstep=True)

print("Partition:      ", x)
print("Bornes gauches: ", x)
print("Bornes droites: ", x + dx)
print("Points milieux: ", (x + dx / 2))
print("Pas:            ", dx)
```

:::

:::remark[Vectorisation]
Remarquez que `x` est un vecteur, et `dx` est un scalaire.
La somme `x + dx` est le vecteur dont les composantes sont les sommes de chaque composante de `x` avec le scalaire `dx`.
:::

par exemple les **points milieux**.

## Calcul d'une moyenne

Rappelons que la _moyenne arithmétique_ de $n$ valeurs $x_1, x_2, \ldots, x_n$ est donnée par la formule:

{tex.display`\bar{x} = \frac{\left(x_1 + x_2 + \cdots + x_n \right)} n`}

En Python, cette formule peut se calculer facilement avec `np.sum` et `len`
{tex.display`\bar{x} = \frac{\overbrace{x_1 + x_2 + \cdots + x_n}^{\texttt{np.sum(x)}}} {\underbrace{n}_{\texttt{len(x)}}}`}

| Fonction    | Rôle                                          |
| ----------- | --------------------------------------------- |
| `np.sum(x)` | Calcule la somme des éléments de la liste `x` |
| `len(x)`    | Calcule le nombre d'éléments de la liste `x`  |

:::example[Moyenne d'un échantillon]
Calculez la valeur moyenne de l'échantillon suivant: $1, 7, 4, 3, 2$.

```python run
import numpy as np

x = [1, 7, 4, 3, 2]
n = len(x)

np.sum(x) / n
```

:::

Nous allons maintenant calculer la valeur moyenne d'une **fonction** sur un intervalle.
La notion de _partition_ nous sera utile,
puisqu'elle nous permet de remplacer un intervalle par un **échantillon fini** de points,
pour lesquels nous savons comment calculer une moyenne.

:::example[Calcul de moyenne]
Estimez la valeur moyenne de la fonction $f(x) = x^2$ sur l'intervalle $[0, 2]$
en utilisant une partition de $100$ intervalles.
Sur chaque sous-intervalle, utilisez le _point milieu_ comme représentant.

::::steps

1. On définit la fonction $f(x) = x^2$ et les variables $a$ et $b$.

   ```python run
   a, b, n = 0, 2, 100

   def f(x):
       return x**2
   ```

2. On partitionne l'intervalle $[0, 2]$ en $100$ sous-intervalles de même longueur,
   et on prend le point milieu `x_m` de chaque sous-intervalle comme représentant.
   On regarde ensuite l'image des points milieux `f(x_m)`.

   ```python run highlight="1,8-9,11"
   import numpy as np

   a, b, n = 0, 2, 100

   def f(x):
       return x**2

   x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)
   x_m = x + dx / 2

   f(x_m)
   ```

   Il suffit de calculer la moyenne de ces valeurs.

3. On calcule la moyenne de ces valeurs

   ```python run highlight="11"
   import numpy as np

   a, b, n = 0, 2, 100

   def f(x):
       return x**2

   x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)
   x_m = x + dx / 2

   np.sum(f(x_m)) / n
   ```

   Ceci donne la réponse correcte, mais réécrivons le code différemment.

4. Rappelez-vous que {tex`\displaystyle \mathrm{d} x = \frac {b - a} n`},
   et donc {tex`\displaystyle n = \frac {b - a} {\mathrm{d} x}`}.
   Au lieu de diviser par $n$, on peut donc multiplier par {tex`\displaystyle \frac {\mathrm{d} x} {b - a}`}.

   ```python run highlight="10"
   import numpy as np

   a, b, n = 0, 2, 100

   def f(x):
       return x**2

   x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)
   x_m = x + dx / 2
   np.sum(f(x_m) * dx) / (b - a)
   ```

   Cette formule paraît plus compliquée,
   mais elle montre le lien plus explicitement avec l'**intégrale**.

::::
:::

Voici donc les principales étapes pour calculer la valeur moyenne d'une fonction sur un intervalle:

```python
# On partitionne l'intervalle [a, b] en n sous-intervalles
x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)

# On calcule les points milieux
x_m = x + dx / 2

# La moyenne est approximée par
np.sum(f(x_m)) / n

# Forme alternative, puisque n = (b - a) / dx
np.sum(f(x_m) * dx) / (b - a)
```

## Cinématique

:::example
Une particule se déplace le long d'une droite avec comme vitesse {tex`v(t) = e^{-t}`}.
Estimez le déplacement net entre $t = 0$ et $t = 2$ en utilisant
les _points milieux_ d'une partition de $100$ intervalles.

::::steps

1. On définit la fonction de vitesse {tex`v(t) = e^{-t}`}

   ```python run highlight="3-4"
   import numpy as np

   def v(t):
       return np.exp(-t)
   ```

2. On découpe notre intervalle de temps $[0, 2]$ en $100$ intervalles de même longueur {tex`\mathrm{d}t`}.

   ```python run highlight="6"
   import numpy as np

   def v(t):
       return np.exp(-t)

   t, dt = np.linspace(0, 2, 100, endpoint=False, retstep=True)
   ```

3. Sur chacun des intervalles,
   imaginons que la vitesse est constante et vaut celle au point milieu.
   Le déplacement se calcule par {tex`\text{vitesse} \times \text{temps},`}
   ce qui donne, sur chaque intervalle,

   {tex.display`\underbrace{\mathrm{d}x}_{\text{déplacement}} = \underbrace{v(t_m)}_{\text{vitesse}} \underbrace{\mathrm{d}t}_{\text{temps}}`}

   ```python run highlight="7,9,10"
   import numpy as np

   def v(t):
       return np.exp(-t)

   t, dt = np.linspace(0, 2, 100, endpoint=False, retstep=True)
   t_m = t + dt / 2

   # Déplacements sur chaque intervalle de la partition
   v(t_m) * dt
   ```

4. Pour obtenir le **déplacement total**,
   il faut sommer tous les déplacements sur chacun des intervalles.

   ```python run highlight="9"
   import numpy as np

   def v(t):
       return np.exp(-t)

   t, dt = np.linspace(0, 2, 100, endpoint=False, retstep=True)
   t_m = t + dt / 2

   np.sum(v(t_m) * dt)
   ```

::::
:::

Le déplacement peut donc être récupéré de la vitesse par le code suivant:

```python
# On partitionne l'intervalle de temps
t, dt = np.linspace(a, b, n, endpoint=False, retstep=True)

# On calcule le point milieu
t_m = t + dt / 2

# On somme les déplacements dx = v(t_m) * dt sur chaque intervalle
np.sum(v(t_m) * dt)
```

## Intégrale définie

Dans les cas ci-dessus,
nous avons obtenu une somme de type

```python
x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)
np.sum(f(x) * dx)
```

Dans toutes nos applications, le résultat est une approximation qui s'améliore lorsque le nombre d'intervalles $n$ augmente.
Le résultat théorique, lorsque $n \to \infty$, est noté

{tex.display`\int_a^b f(x) \, \mathrm dx`}

La quantité ci-dessus s'appelle l'**intégrale définie** de $f$ sur l'intervalle $[a, b]$.

:::remark[Notation]

Le symbole d'intégration {tex`\int`} est en fait l'[ancienne forme de la lettre s minuscule](https://fr.wikipedia.org/wiki/S_long).
Notez la ressemblance formelle:

{tex.display`\underbrace{\int_a^b}_{\text{somme}} f(x) \, \mathrm dx \quad \text{et} \quad \texttt{np.sum(f(x) * dx)}`}

:::

# Aire sous la courbe

Attaquons maintenant le problème classique de l'_aire sous la courbe_.
Nous verrons que ce problème est fondamentalement lié à celui de la moyenne ou du déplacement,
de telle sorte que les méthodes vues ici peuvent également être utilisées pour d'autres applications.

## Méthode du point milieu

Avec une partition de l'intervalle $[a, b]$ en $n$ sous-intervalles,
on peut approximer la surface sous la courbe de la fonction $f$ par des rectangles.
La base des rectangles est donnée par les sous-intervalles de la partition,
et comme son nom l'indique,
la hauteur des rectangles est donnée par la valeur de la fonction $f$ au **point milieu** de chaque sous-intervalle.
En augmentant le nombre de sous-intervalles $n$,
l'approximation devient de plus en plus précise.

<Exercise.RiemannSum
  f={(x) => x ** 2 + 0.5}
  domain={[-2, 2]}
  n={5}
  latex="x^2 + 0.5"
  type="middle"
/>

En d'autres termes, pour chaque sous-intervalle {tex`[x_i, x_{i+1}]`} de la partition,
l'aire du rectangle est donnée par
{tex.display`\underbrace{f\left(\frac{x_i + x_{i+1}} 2\right)}_{\text{hauteur}} \underbrace{\mathrm{d} x}_{\text{base}}, \qquad \mathrm{d} x = x_{i+1} - x_i = \frac {b - a} n`}

Donc l'approximation de l'aire totale est donnée par
{tex.display`f\left(\frac{x_0 + x_1} 2\right) \mathrm{d} x + f\left(\frac{x_1 + x_2} 2\right) \mathrm{d} x + \cdots + f\left(\frac{x_{n-1} + b} 2\right) \mathrm{d} x`}

En Python, l'écriture est plus propre grâce à la vectorisation.

```python
# Partition en n sous-intervalles
x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)

# Points milieux
x_m = x + dx / 2

# Aires des rectangles: hauteur = f(x_m), base = dx
f(x_m) * dx

# Somme des aires des rectangles
np.sum(f(x_m) * dx)
```

Notez la ressemblance du calcul d'aire avec celui de la moyenne ou du déplacement.
L'aire sous la courbe d'une fonction positive $f$ est donc donnée par
{tex.display`\int_a^b f(x) \, \mathrm dx`}

:::example[Méthode du point milieu]
Approximez l'aire sous la courbe de la fonction $\displaystyle f(x) = \frac 1 x$ avec $100$ intervalles entre $x = 1$ et $x = 3$
en utilisant la méthode du **point milieu**.

::::steps

1. On définit la fonction $f(x) = \frac 1 x$.

   ```python run
   import numpy as np

   def f(x):
       return 1 / x
   ```

2. On partitionne l'intervalle $[1, 3]$ en $n = 100$ sous-intervalles de largeur {tex`\mathrm{d}x`},
   pour ensuite calculer les points milieux.

   ```python run highlight="6-7,9"
   import numpy as np

   def f(x):
       return 1 / x

   x, dx = np.linspace(1, 3, 100, endpoint=False, retstep=True)
   x_m = x + dx / 2

   x_m
   ```

3. On somme l'aire des rectangles de largeur {tex`\mathrm{d}x`} et de hauteur $f(x_m)$.

   ```python run highlight="8"
   import numpy as np

   def f(x):
       return 1 / x

   x, dx = np.linspace(1, 3, 100, endpoint=False, retstep=True)
   x_m = x + dx / 2
   np.sum(f(x_m) * dx)
   ```

## Règle des trapèzes

La règle des trapèzes consiste à approximer l'aire sous la courbe par des trapèzes au lieu de rectangles.

<Exercise.RiemannSum
  f={(x) => x ** 2 + 0.5}
  domain={[-2, 2]}
  n={5}
  latex="x^2 + 0.5"
  type="trapezoidal"
/>

Rappelons que l'aire d'un trapèze est donnée par la formule

{tex.display`\text{Aire} = \text{moyenne des bases} \times  \text{hauteur}`}

Nos trapèzes ont pour hauteur {tex`\mathrm{d}x`} et pour bases les valeurs de la fonction $f$ aux bornes gauche et droite de chaque sous-intervalle.
Il suit que l'aire de chaque trapèze est donnée par

{tex.display`\frac {f(x_i) + f(x_{i+1})} 2 \mathrm{d}x`}

En écriture vectorisée, cela donne `(f(x) + f(x + dx)) / 2 * dx`.

```python
# Partition en n sous-intervalles
x, dx = np.linspace(a, b, n, endpoint=False, retstep=True)

# Base moyenne
y = (f(x) + f(x + dx)) / 2

# Somme des aires des trapèzes (hauteur = dx, base moyenne = y)
np.sum(y * dx)
```

:::example
Avec la règle des trapèzes, approximez l'intégrale
{tex.display`\int_0^1 \sqrt{1 - x^2} \, \mathrm dx`}
en employant $100$ sous-intervalles.

::::steps

1. On définit la fonction {tex`\displaystyle f(x) = \sqrt{1 - x^2}`}.

   ```python run
   import numpy as np

   def f(x):
       return np.sqrt(1 - x**2)
   ```

2. On partitionne l'intervalle $[0, 1]$ en $n = 100$ sous-intervalles de largeur {tex`\mathrm{d}x`},
   pour ensuite calculer la base moyenne des trapèzes.

   ```python run highlight="6-7"
   import numpy as np

   def f(x):
       return np.sqrt(1 - x**2)

   x, dx = np.linspace(0, 1, 100, endpoint=False, retstep=True)
   y = (f(x) + f(x + dx)) / 2
   ```

3. On additionne les aires des trapèzes de base moyenne $y$ et de hauteur {tex`\mathrm{d}x`}.

   ```python run highlight="8"
   import numpy as np

   def f(x):
       return np.sqrt(1 - x**2)

   x, dx = np.linspace(0, 1, 100, endpoint=False, retstep=True)
   y = (f(x) + f(x + dx)) / 2
   np.sum(y * dx)
   ```

## Règle de Simpson

Les règles que nous avons vues jusqu'à présent sont des cas particuliers de **moyennes pondérées**.
Elles donnent des poids différents aux bornes gauches, aux points milieux et aux bornes droites de chaque sous-intervalle.
Ainsi, la règle du point milieu ne prend en compte que le point milieu de chaque sous-intervalle,
alors que la règle du trapèze prend en compte les bornes gauches et droites à poids égaux.

|                       | `f(x)`                    | `f(x + dx / 2)` | `f(x + dx)`               |
| --------------------- | ------------------------- | --------------- | ------------------------- |
| Règle du point milieu | $0$                       | $1$             | $0$                       |
| Règle du trapèze      | $\displaystyle \frac 1 2$ | $0$             | $\displaystyle \frac 1 2$ |

:::question
Est-il possible de trouver une combinaison des trois points qui donne la meilleure règle possible?
:::

La meilleure combinaison est donnée par la règle de Simpson,
qui donne des _poids égaux aux extrémités_ et un poids **quatre fois plus grand** au _point milieu_.

|                       | `f(x)`                    | `f(x + dx / 2)`           | `f(x + dx)`               |
| --------------------- | ------------------------- | ------------------------- | ------------------------- |
| Règle du point milieu | $0$                       | $1$                       | $0$                       |
| Règle du trapèze      | $\displaystyle \frac 1 2$ | $0$                       | $\displaystyle \frac 1 2$ |
| Règle de Simpson      | $\displaystyle \frac 1 6$ | $\displaystyle \frac 4 6$ | $\displaystyle \frac 1 6$ |

:::question
D'où vient cette règle?
:::

L'idée centrale est d'approximer $f(x)$ sur chaque intervalle par un polynôme $P(x)$ de degré $2$
qui passe par la borne gauche, le point milieu et la borne droite.
Ensuite, on calcule l'aire exacte sous ce polynôme,
ce que vous apprendrez à faire au cours de maths.

Nous donnons plus de détails à la fin de ce document.

:::example
En employant la règle de Simpson,
calculez l'aire sous la courbe de la fonction {tex`\displaystyle f(x) = \sqrt{1 + x^2}`} sur l'intervalle $[-1, 1]$.

::::steps

1. On définit la fonction {tex`\displaystyle f(x) = \sqrt{1 + x^2}`}.

## Fonctions d'aire (conseillé pour maths)

Considérons une intégrale dont la borne supérieure est un paramètre:
{tex.display`F({\color{red} x}) = \int_{x_0}^{{\color{red} x}} f(t) \, \mathrm{d} t`}

En Python, cela s'écrit simplement (par exemple via la méthode de Simpson)

```python
import numpy as np

def f(x):
    return ...

x0 = ...

def F(x):
    t, dt = np.linspace(x0, x, 200, endpoint=False, retstep=True)
    y = (f(t) + 4 * f(t + dt / 2) + f(t + dt)) / 6
    return np.sum(y * dt)
```

En sciences et en ingénierie,
une quantité importante est la **dérivée de cette fonction d'aire**.

:::example[Dérivée de la fonction d'aire]
Calculez $F$, la fonction d'aire de {tex`f(x) = e^{-x^2}`}.
Ensuite, tracez le graphe de $F'$ (calculé numériquement avec la différence centrale) sur $[-1, 1]$.

::::steps

1. On définit la fonction {tex`f(x) = e^{-x^2}`}.

   ```python run
   import numpy as np

   def f(x):
       return np.exp(-x**2)
   ```

2. On calcule la fonction d'aire avec la méthode de Simpson.

   ```python run math highlight="6-9"
   import numpy as np

   def f(x):
       return np.exp(-x**2)

   def F(x):
       t, dt = np.linspace(0, x, 200, endpoint=False, retstep=True)
       y = (f(t) + 4 * f(t + dt / 2) + f(t + dt)) / 6
       return np.sum(y * dt)
   ```

3. On calcule la dérivée de $F$ avec la différence centrale.

   ```python run math highlight="11-12"
   import numpy as np

   def f(x):
       return np.exp(-x**2)

   def F(x):
       t, dt = np.linspace(0, x, 200, endpoint=False, retstep=True)
       y = (f(t) + 4 * f(t + dt / 2) + f(t + dt)) / 6
       return np.sum(y * dt)

   def diff_F(x, h = 1e-6):
       return (F(x + h) - F(x - h)) / (2 * h)
   ```

4. On trace le graphe de `diff_F` sur l'intervalle $[-1, 1]$.

   ```python run math highlight="1,7,16-18"
   import matplotlib.pyplot as plt
   import numpy as np

   def f(x):
       return np.exp(-x**2)

   @np.vectorize
   def F(x):
       t, dt = np.linspace(0, x, 200, endpoint=False, retstep=True)
       y = (f(t) + 4 * f(t + dt / 2) + f(t + dt)) / 6
       return np.sum(y * dt)

   def diff_F(x, h = 1e-6):
       return (F(x + h) - F(x - h)) / (2 * h)

   x = np.linspace(-1, 1, 100)
   plt.plot(x, diff_F(x), label="F'(x)")
   plt.legend()
   ```

   L'instruction `@np.vectorize` permet de calculer `F(x)` pour un vecteur `x`.
   La raison pour laquelle l'instruction est essentielle est que `x` (potentiellement un vecteur) est utilisé dans la fonction `np.linspace`.

## Ordre d'une méthode et vitesse de convergence

| Méthode              | Convergence |
| -------------------- | ----------- |
| Point milieu         | $n^{-2}$    |
| Méthode des trapèzes | $n^{-2}$    |
| Méthode de Simpson   | $n^{-4}$    |

Ceci veut dire que lorsque $n$ est dix fois plus grand,
l'erreur pour le point milieu ou les trapèzes réduit d'un facteur $100$.
En revanche, l'erreur avec Simpson diminue d'un facteur $10^4$, ce qui est une amélioration significative.

## Interpolation

Nos règles peuvent être vues comme une **moyenne pondérée** de points sur un intervalle,
mais quel poids donner n'est pas évident au premier regard.
Nous présentons un point de vue équivalent,
mais qui cette fois nous donne directement les poids
et nous montre comment généraliser.

Étant donné une fonction $f$,
l'interpolation consiste à trouver un _polynôme_ $P(x)$ de plus petit degré possible qui passe par un certain nombre de points.

La figure ci-dessous montre un exemple d'un polynôme $P$ en bleu qui interpole la fonction $f$.
Bougez les points pour voir le polynôme s'adapter à la fonction.

<Exercise.Interpolation
  x={[-3, 0, 3]}
  f={(x) => 0.2 * x ** 2 + 0.1 * x + 1 / Math.exp(x ** 2 + x)}
/>

Je pourrais vous montrer comment calculer ces [polynômes interpolateurs à la main](https://fr.wikipedia.org/wiki/Interpolation_lagrangienne),
mais la vie est trop courte,
donc nous allons le faire en Python.

:::example
Définissez une fonction `P(x)` qui interpole la fonction $f$ aux points $(1, f(1))$ et $(3, f(3))$.

```python run math
import sympy as sp

f = sp.Function('f')

def P(x):
    return sp.interpolate({ 1: f(1), 3: f(3) }, x)

P(1), P(3)
```

:::

## Formule du trapèze revisitée

Sur chaque sous-intervalle,
remplaçons $f$ par le polynôme $P$ qui passe par les bornes gauche et droite,
et intéressons-nous à l'aire sous $P(x)$.

Pour simplifier, supposons que notre intervalle est $[-3, 3]$,
donc notre polynôme $P$ doit interpoler $f$ aux points $-3$ et $3$.

<Exercise.Interpolation x={[-3, 3]} y={[2, 3]} area />

Remarquez que le polynôme $P$ est une droite,
et l'aire sous $P(x)$ est un trapèze.
En calculant l'intégrale de $P(x)$ avec Python, on obtient

```python run math highlight="8"
import sympy as sp

f, x = sp.Function('f'), sp.Symbol('x')

def P(x):
    return sp.interpolate({ -3: f(-3), 3: f(3) }, x)

sp.integrate(P(x), (x, -3, 3))
```

On voit que les poids (qui doivent être divisés par la longueur de l'intervalle) sont les mêmes pour les deux points,
ce qui est exactement la formule du trapèze.

|                  | `f(x)`                    | `f(x + dx / 2)` | `f(x + dx)`               |
| ---------------- | ------------------------- | --------------- | ------------------------- |
| Règle du trapèze | $\displaystyle \frac 1 2$ | $0$             | $\displaystyle \frac 1 2$ |

## Formule de Simpson

Utilisons cette fois-ci $3$ points équidistants pour interpoler:
la borne gauche, le point milieu et la borne droite.

<Exercise.Interpolation x={[-3, 0, 3]} y={[2, 4, 3]} area />

```python run math highlight="8"
import sympy as sp

f, x = sp.Function('f'), sp.Symbol('x')

def P(x):
    return sp.interpolate({ -3: f(-3), 0: f(0), 3: f(3) }, x)

sp.integrate(P(x), (x, -3, 3))
```

On voit alors que le point milieu $0$ a un poids quatre fois plus grand,
et que les poids sont

|                  | `f(x)`                    | `f(x + dx / 2)`           | `f(x + dx)`               |
| ---------------- | ------------------------- | ------------------------- | ------------------------- |
| Règle de Simpson | $\displaystyle \frac 1 6$ | $\displaystyle \frac 4 6$ | $\displaystyle \frac 1 6$ |

## Formules de Newton-Cotes

On peut se demander si l'idée qui a donné la formule de Simpson pourrait être étendue à plusieurs points.
Et si, sur un intervalle, on utilisait un polynôme $P$ qui passe par $4$ points équidistants au lieu de $3$?

<Exercise.Interpolation x={[-3, -1, 1, 3]} y={[2, 3, 1, 2.5]} area />

```python run math
import sympy as sp

f, x = sp.Function('f'), sp.Symbol('x')

def P(x):
    return sp.interpolate({ -3: f(-3), -1: f(-1), 1: f(1), 3: f(3) }, x)

sp.integrate(P(x), (x, -3, 3))
```

On voit que les deux points milieux doivent avoir un poids trois fois plus grand,
ce qui donne les poids suivants:

| Méthode     | `f(x)`                    | `f(x + dx/3)`             | `f(x + 2*dx/3)`           | `f(x + dx)`               |
| ----------- | ------------------------- | ------------------------- | ------------------------- | ------------------------- |
| Simpson 3/8 | $\displaystyle \frac 1 8$ | $\displaystyle \frac 3 8$ | $\displaystyle \frac 3 8$ | $\displaystyle \frac 1 8$ |

Notez que l'on peut également interpoler avec $5$ points, puis $6$ etc.
En pratique, on ne le fait pas,
car l'interpolation polynomiale est soumise au [phénomène de Runge](https://fr.wikipedia.org/wiki/Ph%C3%A9nom%C3%A8ne_de_Runge):
interpoler avec trop de points peut donner des résultats très mauvais.
Dans la figure ci-dessous,
le polynôme interpolateur en bleu oscille beaucoup plus que la fonction $f$ en rouge.
