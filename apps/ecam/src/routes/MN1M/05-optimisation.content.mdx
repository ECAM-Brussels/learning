# Introduction

Nous présenterons ici deux algorithmes d'optimisation:

1. la méthode de **Newton-Raphson** appliquée à la dérivée première:
   efficace en dimension $1$,
   elle nécessite le calcul de la dérivée seconde,
   ce qui la rend moins performante lorsque la dimension augmente.

2. la **descente de gradient**:
   primitive et lente au premier regard,
   elle ne s'empire pas quand la dimension augmente.
   Elle est un algorithme clé de l'_apprentissage automatique_.

Nous verrons ensuite comment approximer une fonction par un polynôme.

# Dérivées secondes

## Un premier essai infructueux

De manière naïve,
on pourrait dériver deux fois une fonction $f$ en écrivant:

```python run math
def f(x):
    return x**2

def diff(x):
    return f(x + epsilon).dual

def diff2(x):
    return diff(x + epsilon).dual

diff2(1)
```

:::question
Pourquoi cela ne fonctionne-t-il pas?
:::

Notre code est en fait équivalent à

```python run math
def f(x):
    return x**2

f(1 + epsilon + epsilon).dual.dual
```

L'erreur provient de la double application `.dual.dual`.
En prenant la partie duale la première fois,

```python run math
def f(x):
    return x**2

f(1 + epsilon + epsilon).dual
```

on a un nombre réel et non dual,
et `.dual` n'est alors pas défini.

Le `+ epsilon + epsilon` nous met la puce à l'oreille
qu'il faut utiliser **deux nombres duaux différents**,
tel que dans le code suivant.

```python run math
def f(x):
    return x**2

f(1 + epsilon + delta)
```

On voit alors que `.dual.dual` est bien défini:
le premier `.dual` prend la partie duale par rapport à $\epsilon$ (ou $\delta$),
tandis que le second `.dual` prend la partie duale par rapport à $\delta$ (ou $\epsilon$).
D'ailleurs, le code suivant donne bien $2$ qui est la dérivée seconde de $x^2$.

```python run math
def f(x):
    return x**2

f(1 + epsilon + delta).dual.dual
```

## Dérivée automatique seconde

La dérivée automatique seconde fonctionne en utilisant un second nombre dual $\delta$ en plus d'$\epsilon$.
Par exemple, pour la fonction $f(x) = x^2$, si $\epsilon^2 = 0$ et $\delta^2 = 0$, on a

{tex.display`(x + \epsilon + \delta)^2 = x^2 + {\color{green} 2x}\epsilon + \underbrace{\epsilon^2}_0 + {\color{green}2x} \delta + {\color{red} 2}\epsilon\delta + \underbrace{\delta^2}_0,`}

Prendre la partie duale par rapport à $\epsilon$,
puis par rapport à $\delta$,
on obtient le coefficient de $\epsilon\delta$,
qui est bien la dérivée seconde de $x^2$.
On a tout simplement utilisé la dérivée automatique deux fois.
De manière générale, on aura
{tex.display`f(x + \epsilon + \delta) = f(x) + {\color{green} f'(x)} \epsilon + {\color{green} f'(x)} \delta + {\color{red} f''(x)} \epsilon \delta`}

:::question
Comment calculer une dérivée seconde?
:::

Si l'on a également besoin de la dérivée première,
on peut procéder en deux étapes,
en s'assurant d'employer deux nombres duaux **différents** pour chaque dérivée:

```python run math
import numpy as np

def f(x):
    return x**2

def diff(x):
    return f(x + epsilon).dual

def diff2(x):
    return diff(x + delta).dual

diff2(1)
```

Si seule la dérivée seconde est nécessaire,
on peut se contenter d'une étape et écrire

```python run math
def f(x):
    return x**2

def diff2(x):
    return f(x + epsilon + delta).dual.dual

diff2(1)
```

:::remark[Nombres duaux imbriqués]
En employant $\epsilon$ et $\delta$,
nos nombres peuvent maintenant prendre la forme

{tex.display`\underbrace{(a + b \delta)}_{\text{partie "réelle" p/r à }\epsilon} + \underbrace{(c + d \delta)}_{\text{partie "duale" p/r à }\epsilon} \epsilon`}

En d'autres termes, nos nombres duaux en $\delta$ sont **imbriqués** dans des nombres duaux en $\epsilon$.
L'instruction `.dual.dual` sur le nombre ci-dessus prend alors son sens et donne $d$, le coefficient de $\epsilon\delta$.
On peut le vérifier en Python avec l'exemple suivant:

```python run math
expr = (1 + 2 * delta) + (3 + 4 * delta) * epsilon
expr.dual.dual
```

D'ailleurs, dans notre environnement de calcul,
`epsilon` et `delta` sont définis
de telle sorte que $\delta$ soit imbriqué:

```python run math
epsilon = Dual(0, 1)
delta = Dual(Dual(0, 1), 0)
```

:::

:::example
Définissez la fonction `diff2(x)` qui est la dérivée seconde de {tex`\displaystyle f(x) = \frac {x^2 + 3} {x - 4}`}.
::::steps

1. On définit la fonction $f(x)$:

   ```python run math
   def f(x):
       return (x**2 + 3) / (x - 4)
   ```

2. On calcule la dérivée première:

   ```python run math highlight="4-5"
   def f(x):
       return (x**2 + 3) / (x - 4)

   def diff(x):
       return f(x + epsilon).dual
   ```

3. On calcule la dérivée seconde:

   ```python run math highlight="7-8"
   def f(x):
       return (x**2 + 3) / (x - 4)

   def diff(x):
       return f(x + epsilon).dual

   def diff2(x):
       return diff(x + delta).dual
   ```

4. On aurait pu, si on le souhaite, calculer directement la dérivée seconde

   ```python run math highlight="7-8"
   def f(x):
       return (x**2 + 3) / (x - 4)

   def diff2(x):
       return diff(x + epsilon + delta).dual.dual
   ```

# Newton-Raphson pour l'optimisation

Une étape utile pour optimiser est la résolution de l'équation $f'(x) = 0$.
Souvenez-vous que l'on a appris à trouver une racine _numériquement_ avec la méthode de Newton-Raphson.

On appliquera alors Newton-Raphson à la **dérivéé**.
Pour rappel, la méthode de Newton-Raphson consiste à remplacer $f$ par sa tangente,
et espérer que la racine de cette dernière est proche de celle de $f$.
En **réitérant**, on améliore notre estimation.

|                     | Newton-Raphson classique                                        | Newton-Raphson pour l'optimisation                                |
| ------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| Équation            | $f(x) = 0$                                                      | $f'(x) = 0$                                                       |
| Itération           | {tex`\displaystyle x_{n + 1} = x_n - \frac {f(x_n)} {f'(x_n)}`} | {tex`\displaystyle x_{n + 1} = x_n - \frac {f'(x_n)} {f''(x_n)}`} |
| Itération en Python | `x = x - f(x) / diff(x)`                                        | `x = x - diff(x) / diff2(x)`                                      |

Dans le schéma ci-dessus,
remarquez qu'on applique Newton-Raphson à $f'$ (bleu clair).
On part de $x_0$, on se dirige verticalement vers le graphe.
Ensuite, on se déplace _le long de la tangente_ vers la **racine**, qu'on appelle $x_1$.
On recommence ensuite.

:::example
En employant 5 itérations de la méthode de Newton-Raphson,
trouvez le minimum de {tex`\displaystyle f(x) = x^2 + 3x + 5`} en partant de $x = 0$.

::::steps

1. On définit la fonction $f(x)$

   ```python run math
   def f(x):
       return x**2 + 3*x + 5
   ```

2. On calcule $f'(x)$ et $f''(x)$:

   ```python run math highlight="4-8"
   def f(x):
       return x**2 + 3*x + 5

   def diff(x):
       return f(x + epsilon).dual

   def diff2(x):
       return diff(x + delta).dual
   ```

3. On applique la méthode de Newton-Raphson à la dérivée première:

   ```python run math highlight="10-14"
   def f(x):
       return x**2 + 3*x + 5

   def diff(x):
       return f(x + epsilon).dual

   def diff2(x):
       return diff(x + delta).dual

   x = 0
   for i in range(5):
       x = x - diff(x) / diff2(x)

   x
   ```

## Condition d'arrêt

Appliquer $5$ ou $10$ itérations de Newton-Raphson semble _arbitraire_.
Comment sait-on si cela sera suffisant?

Puisque notre but est d'avoir $f'(x) = 0$,
il est naturel de s'arrêter lorsque $f'$ est suffisamment proche de $0$,
par exemple lorsque {tex.display`|f'(x)| \leq 10^{-6}`}

On appelle cela une **condition d'arrêt**.
En Python, ceci se fait avec une boucle `while` (qui veut dire _tant que_ en français):

```python
# Tant que |f'(x)| > 10^(-6)...
while np.abs(diff(x)) > 1e-6:
    # On applique Newton-Raphson à f'
    x = x - diff(x) / diff2(x)
```

De nouveau, seules les **lignes indentées** sont répétées.

Remarquez que la _condition_ de la boucle `while` est le **contraire** de la condition d'arrêt.
Ceci est dû au fait qu'avec `while` on spécifie quand continuer et non pas quand s'arrêter.

| Condition d'arrêt      | Boucle `while`                    |
| ---------------------- | --------------------------------- |
| {tex`f'(x) \leq 0.01`} | `while np.abs(diff(x)) > 0.01:`   |
| {tex`f'(x) < 0.001`}   | `while np.abs(diff(x)) >= 0.001:` |

:::example
En utilisant la condition d'arrêt $|f'(x)| \leq 10^{-7}$,
trouvez le minimum de {tex`\displaystyle f(x) = x^2 + 3x + 1`} en partant de $x = 3$.

::::steps

1. On définit la fonction $f(x)$ et ses dérivées première et seconde:

   ```python run math
   def f(x):
       return x**2 + 3*x + 1

   def diff(x):
       return f(x + epsilon).dual

   def diff2(x):
       return diff(x + delta).dual
   ```

2. On applique la méthode de Newton-Raphson à la dérivée première:

   ```python run math highlight="1,12-16"
   import numpy as np

   def f(x):
       return x**2 + 3*x + 1

   def diff(x):
       return f(x + epsilon).dual

   def diff2(x):
       return diff(x + delta).dual

   x = 3
   while np.abs(diff(x)) > 1e-7:
       x = x - diff(x) / diff2(x)

   x
   ```

# Descente de gradient

L'idée de la _descente de gradient_ est simple.
On améliore progressivement notre estimation du minimum en utilisant la _pente_ de la fonction.
Le minimum est-il à gauche ou à droite de notre estimation?
On se déplace ensuite dans cette direction et on recommence.

Supposons qu'on ait une estimation $x_n$ du minimum de $f$.
Deux cas se présentent:

- Si $f'(x_n) > 0$, la pente est positive et donc le minimum se trouve _à gauche_ de $x_n$.

    <Board.Axis from={[0, 0]} to={[0, 1]} ticks={{ visible: false }} />
    <Board.Axis from={[0, 0]} to={[1, 0]} ticks={{ visible: false }} />
    <Board.Plot fn={(x) => x ** 2 - 4.5} fixed />
    <Board.Plot
      fn={(x) => 4 * (x - 2) - 0.5}
      domain={[1.8, 2.2]}
      color="darkgreen"
      strokeWidth={3}
    />
    <Board.Point position={[2, -0.5]} fixed name="x_n" />
  </Board>

  Donc si $f'(x_n)$ est **positif**, on veut {tex`x_{n + 1} < x_n`}, c'est-à-dire un déplacement vers la **gauche**.
  Notez que c'est le cas avec
  {tex.display`x_{n + 1} = x_n - \underbrace{\eta f'(x_n)}_{> 0}, \qquad \qquad \eta > 0`}.

  La formule ci dessus veut dire que l'on part de $x_n$
  et que l'on se déplace dans la direction opposée de la pente $f'(x_n)$
  puisque la quantité $\eta$ est une **constante** strictement positive.

- Si $f'(x) < 0$, la pente est négative, donc le minimum se trouve _à droite_ de $x$.

  <Board class="h-96 w-96">
    <Board.Axis from={[0, 0]} to={[0, 1]} ticks={{ visible: false }} />
    <Board.Axis from={[0, 0]} to={[1, 0]} ticks={{ visible: false }} />
    <Board.Plot fn={(x) => x ** 2 - 4.5} fixed />
    <Board.Plot
      fn={(x) => -4 * (x + 2) - 0.5}
      domain={[-2.2, -1.8]}
      color="darkgreen"
      strokeWidth={3}
    />
    <Board.Point position={[-2, -0.5]} fixed name="x" />
  </Board>

  Donc si $f'(x_n)$ est **négatif**, on veut {tex`x_{n + 1} > x_n`}, c'est-à-dire un déplacement vers la **droite**.
  Notez que c'est le cas avec
  {tex.display`x_{n + 1} = x_n - \underbrace{\eta f'(x_n)}_{< 0}, \qquad \qquad \eta > 0`}.

  La formule ci dessus veut dire que l'on part de $x_n$
  et que l'on se déplace dans la direction opposée de la pente $f'(x_n)$,
  puisque la quantité $\eta$ est une **constante** strictement positive.

:::remark[Descente de gradient]
L'itération {tex.display`x_{n + 1} = x_n - \eta f'(x_n)`} est appelée **descente de gradient**.

Son nom provient du fait que l'on se déplace dans la direction opposée de la pente
(le gradient est la généralisation de la pente en dimension supérieure).
:::

:::remark[Taux d'apprentissage]
La constante $\eta$ est nécessaire pour s'assurer que les déplacements ne sont pas trop grands.
Imaginons que $f'(x_n) = 1000$, alors {tex`x_{n + 1} = x_n - 1000`} est un déplacement énorme.
Cette constante a pour nom le **taux d'apprentissage**.

En revanche, si $\eta$ est trop petit, les déplacements seront minuscules
et plus de temps sera nécessaire pour atteindre le minimum.
:::

En pratique, une seule ligne change entre Newton-Raphson et la descente de gradient: l'itération

|                      | Newton-Raphson                                                    | Descente de gradient                  |
| -------------------- | ----------------------------------------------------------------- | ------------------------------------- |
| Itération            | {tex`\displaystyle x_{n + 1} = x_n - \frac {f'(x_n)} {f''(x_n)}`} | {tex`x_{n + 1} = x_n - \eta f'(x_n)`} |
| Code Python          | `x = x - diff(x) / diff2(x)`                                      | `x = x - eta * diff(x)`               |
| Dérivées nécessaires | $f'(x)$ et $f''(x)$                                               | seulement $f'(x)$                     |

Prenez un moment pour utiliser l'animation ci-dessous.
D'abord, faites augmenter $n$ pour voir les déplacements successifs,
ensuite, changez le taux d'apprentissage $\eta$ pour voir l'effet sur la vitesse de convergence.

## Dérivées d'ordre supérieur

Jusqu'à présent, nous employions $\epsilon$ pour la dérivée première et $\delta$ pour la dérivée seconde.
Pour une dérivée d'ordre supérieur, on peut continuer à ajouter des nombres duaux,
ce qui est fastidieux.
Pour vous aider, nous avons défini la fonction `eps(n)` qui donne pour chaque valeur de $n$ un nombre dual différent.

On peut donc utiliser `eps(1)` pour la dérivée première, `eps(2)` pour la dérivée seconde, et ainsi de suite:

```python run math
(1 + eps(1) + eps(2))**2
```

Il est possible de calculer les dérivées d'ordre arbitraire de manière très concise:

```python
def diff(n, x):
    if n == 0:
        return ... # Expression analytique de f(x)
    else:
        return diff(n - 1, x + eps(n)).dual
```

:::example
Définissez la fonction `diff(n, x)` qui est la dérivée d'ordre `n` de {tex`\displaystyle f(x) = e^x \sin x`}.

::::steps

1. On remarque que `diff(0, x)` est simplement la fonction elle-même
   puisque c'est une dérivée d'ordre $0$.
   Dès lors, si $n = 0$, on retourne $e^x \sin x$.

   ```python run math highlight="4-5"
   import numpy as np

   def diff(n, x):
        if n == 0:
            return np.exp(x) * np.sin(x)
   ```

2. Autrement, lorsque $n > 0$,
   `diff(n, x)` est simplement la dérivée de `diff(n - 1, x)`:

   ```python run math
   import numpy as np

   def diff(n, x):
        if n == 0:
            return np.exp(x) * np.sin(x)
        else:
            return diff(n - 1, Dual(x, 1)).dual
   ```

## Formule de Maclaurin

La formule de Maclaurin permet d'approximer une fonction autour de $0$ par un polynôme:

{tex.display`f(x) \approx f(0) + f'(0) x + f''(0) \frac {x^2} {2!} + f'''(0) \frac {x^3} {3!} + \dots + f^{(N)}(0) \frac {x^N} {N!},`}

où $n! = 1 \cdot 2 \cdot 3 \cdots n$ est la factorielle de $n$.
Le membre de droite s'appelle le **polynôme de Maclaurin d'ordre N**.

:::example[Polynôme de Maclaurin]
Pour $f(x) = e^x$, {tex`f^{(n)}(x) = e^x`} donc {tex`f^{(n)}(0) = 1`}.
Dès lors, la formule de Maclaurin devient:

{tex.display`e^x \approx 1 + x + \frac {x^2} {2!} + \frac {x^3} {3!} + \dots + \frac {x^N} {N!}.`}

En fait, l'exponentielle est implémentée sur les ordinateurs par cette formule.
:::

À titre d'exemple, voici la fonction $f(x) = \sin x$ approximée par un polynôme de Maclaurin d'ordre $5$:

<Exercise.MaclaurinAnimation />

Remarquez que chacun des termes a la forme:

{tex.display`f^{(n)}(0) \frac {x^n} {n!}`}

La traduction en Python ne devrait pas être trop difficile sachant que

- $n!$ est calculé avec `math.factorial(n)`,
- {tex`f^{(n)}(0)`} est calculé avec `diff(n, 0)` défini précédemment.

Dès lors,
le polynôme de Maclaurin d'ordre $N$ s'écrit en Python comme suit:

```python
import math

def maclaurin(x, N):
    return sum([diff(n, 0) * x**n / math.factorial(n) for n in range(N + 1)])
```

:::example

Sur $[-3, 3]$,
tracez les graphes suivants:

- $f(x) = \sin x$
- son approximation de Maclaurin d'ordre $3$.
- son approximation de Maclaurin d'ordre $5$.

::::steps

1. On calcule les dérivées d'ordre $n$ de {tex`\sin x`} avec la dérivation automatique:

   ```python run math highlight="3-7"
   import numpy as np

   def diff(n, x):
       if n == 0:
           return np.sin(x)
       else:
           return diff(n - 1, x + eps(n)).dual
   ```

2. On définit l'approximation polynomiale
   {tex.display`f(x) \approx \sum_{n = 0}^N f^{(n)}(0) \frac {x^n} {n!}`}

   ```python run math highlight="1,10-11"
   import math
   import numpy as np

   def diff(n, x):
       if n == 0:
           return np.sin(x)
       else:
           return diff(n - 1, x + eps(n)).dual

   def maclaurin(x, N):
       return sum([diff(n, 0) * x**n / math.factorial(n) for n in range(N + 1)])
   ```
