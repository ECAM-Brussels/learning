# Introduction

L'objectif de ce chapitre est de calculer des **dérivées**.
À cette fin, on rappelle que $f'(x)$ est définie par

{tex`f'(x)
= \lim_{h \to 0} \frac{\overbrace{f(x + h) - f(x)}^{\Delta y}} {\underbrace{h}_{\Delta x}}.`}

Malheureusement,
nous verrons que le concept de **limite** est _problématique en calcul numérique_,
car la précision est limitée, surtout si on s'éloigne de $0$.
Une tension apparaîtra:

- D'un côté, les mathématiques nous disent que $h$ doit être petit.

- De l'autre, le _calcul numérique_ nous dit que si $h$ est trop petit,
  les erreurs d'arrondi deviennent trop importantes et faussent le résultat.

Nous verrons que le problème s'empire si l'on calcule des dérivées d'ordre supérieur.

# Pentes et droites

Rappelons que la **pente** d'une droite passant par deux points $(x_1, y_1)$ et $(x_2, y_2)$ est donnée par

{tex`\text{pente}
= \frac{\Delta y}{\Delta x}
= \frac{y_2 - y_1}{x_2 - x_1}.`}

# Quotient différentiel

La dérivée se définit comme ceci
{tex`f'(x)
= \lim_{h \to 0} \frac {f(x + h) - f(x)} h.`}

En particulier, si $h$ est petit
{tex`f'(x)
\approx \frac {f(x + h) - f(x)} h.`}

Nous allons utiliser cette approximation pour calculer des dérivées.

:::definition[Quotient différentiel]

Le **quotient différentiel** de $f$ en $x$ est défini par
{tex`\frac {f(x + h) - f(x)}{h},
\quad h \neq 0.`}

La quantité $|h|$ est appelée le **pas**.
:::

:::example

Approximons la dérivée de $f(x) = \ln (x^2 + 1)$ en $x = 0$ avec le _quotient différentiel_ de pas $h = 10^{-6}$.

```python run
import numpy as np

def f(x):
    return np.log(x**2 + 1)

h = 1e-6
x = 0

(f(x + h) - f(x)) / h
```

La valeur théorique est
{tex`f'(0)
= \left. \frac{2x}{x^2 + 1} \right|_{x = 0}
= 0.`}

:::

:::example

Approximons la dérivée de $f(x) = x^2 + 1$ en $x = 1$
avec comme pas $h = 10^{-30}$.

```python run
import numpy as np

def f(x):
    return x**2 + 1

def diff(x, h = 1e-6):
    return (f(x + h) - f(x)) / h

diff(1, 1e-30)
```

Le résultat n'est **absolument pas correct**,
puisque nous aurions dû obtenir:
{tex`f'(1)
= \left. 2x \right|_{x = 1}
= 2.
`}

Souvenez-vous que Python n'utilise qu'environ $15$ chiffres significatifs,
ce qui signifie que pour Python, $1 + h = 0$:

```python run
h = 1e-30
1 + h
```

L'erreur se propage alors

{tex`\frac {(\overbrace{1 + h}^1)^2 - 1^2} h
= \frac 0 h
= 0
`}

:::

:::exercise

<Exercise.Differences />

:::

Lorsque $h$ est trop petit,
on voit que le calcul numérique n'est pas fiable pour approximer la dérivée.

:::example

Approximons la dérivée de $f(x) = \sin x$ en $x = 0$.
Le résultat théorique devrait être:
{tex`f'(0)
= \left. \cos x \right|_{x = 0}
= 1`}

```python run
import numpy as np

def f(x):
    return np.sin(x)

def diff(x, h = 1e-6):
    return (f(x + h) - f(x)) / h

diff(0, 1e-30)
```

Le résultat est ici **correct**.
Ceci est dû au fait que en $x = 0$, $f(x) = 0$.
Comme il y a plus de nombres représentables autour de $0$,
il y a beaucoup moins de perte de précision lors du calcul de $f(x + h) - f(x)$.

:::

:::remark
À l'examen,
il est nécessaire de pouvoir expliquer
quand et pourquoi le résultat devient $0$.
:::

## En avant, en arrière, ou central

Pour $h > 0$, on distingue trois types de **quotients différentiels**:

import differentialQuotients from './differential-quotients.jpg'

<img
  class="mx-auto rounded-xl border border-gray-200 shadow-lg"
  src={differentialQuotients}
  alt="Différence avant, arrière et centrale"
/>

Le **quotient différentiel central** est la **moyenne arithmétique** des quotients avant et arrière.
Étant donné qu'il tient compte de ce qui se passe de part et d'autre de $x$,
il se rapproche plus vite de la valeur théorique de la dérivée.

Nous privilégierons dès lors l'emploi du **quotient différentiel central**.

# Fonctions dérivées

La _fonction dérivée_ d'une fonction $f$

{tex`x \mapsto
f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}`}

Nous feront en chaque point une _approximation numérique_ de la dérivée
par un _quotient différentiel_.

<Geogebra id="kT87vrax" />

:::example[Approximation de la fonction dérivée]

Approximons la fonction dérivée de {tex`f(x) = e^{-x^2}`} pour $x \in [-1, 1]$ avec le _quotient différentiel central_ de pas $h = 10^{-6}$,
Ensuite, tracez le graphe de la fonction dérivée théorique et celui de l'approximation numérique.

```python run math
import matplotlib.pyplot as plt
import numpy as np

def f(x):
    return np.exp(-x**2)

def diff(x, h = 1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

x = np.linspace(-1, 1, 100)
plt.plot(x, -2*x*np.exp(-x**2), label="f'(x)")
plt.plot(x, diff(x), '--', label="approximation numérique")
plt.legend()
```

On constate que l'approximation numérique est proche de la fonction dérivée théorique.

:::

:::example

Tracez le graphe de la dérivée de {tex`f(x) = e^{-x^2}`} pour $x \in [-1, 1]$,
et celui du _quotient différentiel avant_ pour $h = 10^{-6}$ et $h = 10^{-20}$.

```python run math
import matplotlib.pyplot as plt
import numpy as np

def f(x):
    return np.exp(-x**2)

def diff(x, h = 1e-6):
    return (f(x + h) - f(x)) / h

x = np.linspace(-1, 1, 1000)

plt.subplot(2, 1, 1)
plt.title("h = 1e-6")
plt.xlabel("x")
plt.ylabel("y")
plt.plot(x, -2*x*np.exp(-x**2), label="f'(x)")
plt.plot(x, diff(x, 1e-6), label="diff(x)")
plt.legend()

plt.subplot(2, 1, 2)
plt.title("h = 1e-20")
plt.xlabel("x")
plt.ylabel("y")
plt.plot(x, -2*x*np.exp(-x**2), label="f'(x)")
plt.plot(x, diff(x, 1e-20), label="diff(x)")
plt.legend()
plt.tight_layout()
```

# Dérivées secondes

En prenant la différence centrale de la différence centrale, on obtient une approximation de la dérivée seconde

{tex.display`\approx \frac{f(x + 2h) - 2 f(x) + f(x - 2h)}{4 h^2}`}

Dans le cadre de cette activité,
nous privilégierons l'_application répétée_ de la différence centrale.

:::remark

En arithmétique exacte, il n'y a aucune différence entre

{tex.display`\approx \frac{f(x + 2h) - 2 f(x) + f(x - 2h)}{4 h^2}`}

et une double application de la différence centrale.
Cependant, en pratique, la double application nécessite plus de calculs et est donc plus sensible aux erreurs d'arrondi.

La formule ci-dessus, en revanche, a été simplifiée en _arithmétique exacte_
pour réduire le nombre de calculs.

:::

:::example[Derivée seconde numérique]
Approximons la dérivée seconde de {tex`f(x) = \sin x`}
en appliquant deux fois la différence centrale
avec $h = 10^{-6}$,
et graphez le résultat sur $[-\pi, \pi]$.

```python run math highlight="12,13"
import matplotlib.pyplot as plt
import numpy as np

h = 1e-6

def f(x):
    return np.sin(x)

def diff(x):
    return (f(x + h) - f(x - h)) / (2 * h)

def diff2(x):
    return (diff(x + h) - diff(x - h)) / (2 * h)

x = np.linspace(-np.pi, np.pi, 100)
plt.plot(x, -np.sin(x), label="f''(x)")
plt.plot(x, diff2(x), '--', label="approx f''")
plt.legend()
```

:::

:::remark[Récursion]
Au lieu de définir une fonction pour chaque dérivée,
où chaque fonction fait essentiellement la même chose,
on peut faire en sorte qu'une fonction s'**appelle elle-même** autant de fois que nécessaire.

On pourrait calculer la dérivée d'ordre $n$ de $f$ avec la fonction récursive suivante:

```python run
def diff(x, n):
    if n == 0:
        return f(x)
    else:
        return (diff(x + h, n - 1) - diff(x - h, n - 1)) / (2 * h)
```

L'idée est simple:

- Pour la dérivée d'ordre $0$,
  on retourne simplement $f(x)$
  puisqu'il n'est pas nécessaire de dériver.

- Pour les autres dérivées d'ordre $n$, on applique la _différence centrale_ à notre approximation de la dérivée d'ordre $n - 1$,
  qui est elle-même calculée comme étant une différence centrale de la dérivée d'ordre $n - 2$, et ainsi de suite.

:::

:::example[Empirement de la précision]

```python run math
import matplotlib.pyplot as plt
import numpy as np

h = 1e-8

def f(x):
    return np.exp(x)

def diff(x):
    return (f(x + h) - f(x - h)) / (2 * h)

def diff2(x):
    return (diff(x + h) - diff(x - h)) / (2 * h)

x = np.linspace(-1, 1, 100)
plt.plot(x, f(x), label="f")
plt.plot(x, diff(x), '--', label="approx f'")
plt.plot(x, diff2(x), '--', label="approx f''")
plt.legend()
```

:::
