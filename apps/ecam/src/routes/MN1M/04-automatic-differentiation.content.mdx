# Introduction

Nous avons vu que l'approximation

{tex.display`f'(a) \approx \frac{f(a + h) - f(a)} h`}

est _numériquement instable_.
Nous verrons aujourd'hui
une méthode qui permet de calculer $f'(a)$ _automatiquement_,
avec une réponse aussi _exacte_ que le permet l'arithmétique de l'ordinateur.

# Dérivation automatique

## Un exemple introductif

<Exercise.FirstExample />

:::remark

Si l'hypothèse $\epsilon \neq 0$ mais $\epsilon^2 = 0$ peut vous sembler absurde,
elle a du sens dans le contexte du calcul numérique.
En effet,

```python run
epsilon = 1e-10
1 + epsilon
```

Cependant $\epsilon^2$ n'est pas significatif par rapport à $1$,
et vaut effectivement $0$ dans le calcul suivant:

```python run
epsilon = 1e-10
1 + epsilon**2
```

:::

## Un exemple plus représentatif

Imaginons que nous souhaitions calculer la dérivée de $f(x) = x^2$ en $x = 3$.
Dans un cours de mathématiques classique,
nous procédons généralement en deux étapes:

1. On calcule la _fonction dérivée_: $f'(x) = 2x$

2. On remplace $x$ par $3$ pour obtenir $f'(3) = 6$

En dérivation automatique, le calcul de la _fonction dérivée_ n'est pas nécessaire,
puisqu'il suffit de calculer $f(3 + \epsilon)$:

:::example
Calculez la dérivée de $f(x) = x^2$ en $x = 3$ par la **dérivation automatique**:

1. Dans $f(x)$, on remplace $x$ par $3 + \epsilon$:

{tex.display`\begin{align*}
  f(3 + \epsilon)
    &= (3 + \epsilon)^2\\
    &= 9 + 6\epsilon + \epsilon^2
\end{align*}`}

2. En utilisant $\epsilon^2 = 0$, on obtient

{tex.display`f(3 + \epsilon) = \underbrace{9}_{f(3)} + \underbrace{6}_{f'(3)} \epsilon`}

3. On lit $f'(3) = 6$.

:::

## Nombres duaux

Un **nombre dual** est un nombre sous la forme

{tex`a + b \epsilon,
\quad a, b \in \mathbb{R}`}

1. Les règles arithmétiques usuelles s'appliquent avec comme seule différence que $\epsilon^2 = 0$.

2. Si $f$ est une fonction réelle dérivable,
   on l'étend sur les nombres duaux via $$f(a + b \epsilon) = f(a) + f'(a) b \epsilon$$

:::remark[Redondance]
Si $f(x) = x^2$, alors $f'(x) = 2x$, et donc

{tex.display`\underbrace{\epsilon^2}_{f(\epsilon)} = f(0 + 1 \epsilon) = f(0) + f'(0) \epsilon = 0`}

:::

:::example
Si $g(x) = \sin(x^2)$,
calculons $g(x + \epsilon)$.

**Première manière**. On emploie la seconde règle de calcul directement
{tex.display`g(x + \epsilon) = g(x) + g'(x) \epsilon = \sin(x^2) + (2x\cos(x^2)) \epsilon`}

**Seconde manière** (via la composition). On calcule d'abord le carré
{tex`g(x + \epsilon)
  = \sin((x + \epsilon)^2)
  = \sin(x^2 + 2x\epsilon + \underbrace{\epsilon^2}_0)
`}

En utilisant $\sin(a + b \epsilon) = \sin(a) + b \cos(a) \epsilon$, on obtient
{tex.display`g(x + \epsilon) = \underbrace{\sin(x^2)}_{g(x)} + \underbrace{(2x\cos(x^2))}_{g'(x)} \epsilon`}
:::

:::remark[Règle de composée]
La deuxième manière est plus longue,
mais elle révèle un fait important:
la règle de dérivée est **automatiquement appliquée**.
Plus de détails dans la sous-section suivante.
:::

### Règles de calcul

<Exercise.Rules />

:::remark[Dérivée de composée]
La règle $f(a + b \epsilon) = f(a) + f'(a) b \epsilon$ applique automatiquement la **règle de la composée**.

{tex.display`g(x + \epsilon) = g(x) + g'(x) \epsilon`}

En appliquant $f$ des deux côtés, on obtient:

{tex.display`\begin{align*}
f(g(x + \epsilon))
  &= f(\underbrace{g(x)}_a + \underbrace{g'(x)}_b \epsilon)\\
  &= f(\underbrace{g(x)}_a) + f'(\underbrace{g(x)}_a) \underbrace{g'(x)}_b \epsilon\\
\end{align*}`}

On obtient alors
{tex.display`(f \circ g)(x + \epsilon)) = f(g(x)) + f'(g(x)) g'(x) \epsilon`}
:::

## Dérivation automatique avec Python

$$

f(x + \epsilon) = f(x) + f'(x) \epsilon


$$

En évaluant $f(a + \epsilon)$, on obtient donc $f(a)$ et $f'(a)$ en une seule évaluation.

:::example

Calculez la dérivée de $f(x) = \sin(x^2)$ en $x = 1$ en utilisant la dérivation automatique.

::::steps

1. On définit la fonction $f(x) = \sin(x^2)$.

   ```python run math
   import numpy as np

   def f(x):
       return np.sin(x**2)
   ```

2. On évalue notre fonction $f$ en $x = 1 + \epsilon$.

   ```python run math highlight="6"
   import numpy as np

   def f(x):
       return np.sin(x**2)

   f(1 + epsilon)
   ```

### Dérivée de fonctions

La vectorisation permet facilement de calculer la dérivée d'une fonction sur un intervalle.

:::example

Calculez la dérivée de $f(x) = \sin(x)$ sur l'intervalle $[-\pi, \pi]$,
ensuite tracez la fonction et sa dérivée.

::::steps

1. On définit la fonction $f(x) = \sin(x)$.

   ```python run math
   import numpy as np

   def f(x):
       return np.sin(x)
   ```

2. On calcule la dérivée $f'(x)$ grâce à la dérivation automatique.

   ```python run math highlight="6-7"
   import numpy as np

   def f(x):
       return np.sin(x)

   def diff(x):
       return f(x + epsilon).dual
   ```

3. On trace le graphique de $f(x)$ et $f'(x)$ sur l'intervalle $[-\pi, \pi]$.

   ```python run math highlight="1,10-13"
   import matplotlib.pyplot as plt
   import numpy as np

   def f(x):
       return np.sin(x)

   def diff(x):
       return f(x + epsilon).dual

   x = np.linspace(-np.pi, np.pi, 100)
   plt.plot(x, f(x), label="f(x)")
   plt.plot(x, diff(x), label="f'(x)")
   plt.legend()
   ```

### Tangentes

:::example
Calculez la tangente à la courbe $f(x) = \sin(x^2)$ en $x = 1$.
Graphez la fonction et sa tangente sur l'intervalle $[0, 2]$.

::::steps

1. On définit la fonction $f(x) = \sin(x^2)$.

   ```python run math
   import numpy as np

   def f(x):
       return np.sin(x**2)
   ```

2. On calcule la dérivée $f'(1)$ grâce à la dérivation automatique.

   ```python run math highlight="6-7"
   import numpy as np

   def f(x):
       return np.sin(x**2)

   # f(1) + f'(1) ε
   f(1 + epsilon)
   ```

   Dans la sortie, la partie réelle est $f(1)$ et la partie duale est $f'(1)$.

3. On définit la fonction de la tangente $t(x) = f'(1)(x - 1) + f(1)$.

   ```python run math highlight="6-10"
   import numpy as np

   def f(x):
       return np.sin(x**2)

   def t(x):
       result = f(1 + epsilon) # f(1) + f'(1) ε
       m = result.dual # f'(1)
       y0 = result.real # f(1)
       return m * (x - 1) + y0
   ```

4. On trace le graphique de $f(x)$ et de sa tangente $t(x)$ sur l'intervalle $[0, 2]$.

   ```python run math highlight="1,13-16"
   import matplotlib.pyplot as plt
   import numpy as np

   def f(x):
       return np.sin(x**2)

   def t(x):
       result = f(1 + epsilon)
       m = result.dual
       y0 = result.real
       return m * (x - 1) + y0

   x = np.linspace(0, 2, 100)
   plt.plot(x, f(x), label="f(x)")
   plt.plot(x, t(x), label="t(x)")
   plt.legend()
   ```

# Newton-Raphson

L'idée derrière la méthode de Newton-Raphson est la suivante:
si trouver la racine de $f(x)$ est difficile,
remplaçons $f(x)$ par sa tangente.

<Exercise.RootFormula />

Dans l'illustration ci-dessous,
on ne connaît pas la racine de $f(x)$,
mais

:::example
Déterminez une racine approchée de {tex`f(x) = e^{-x^2} - \frac{1}{2}`} en approximant $f(x)$ par sa tangente autour de $x_0 = 0.8$.

::::steps

1. On définit la fonction {tex`f(x) = e^{-x^2} - \frac{1}{2}`}.

   ```python run math
   import numpy as np

   def f(x):
       return np.exp(-x**2) - 0.5
   ```

2. On calcule la tangente $t(x) = f'(x_0)(x - x_0) + f(x_0)$ en $x_0 = 0.8$.

   ```python run math highlight="6-11"
   import numpy as np

   def f(x):
       return np.exp(-x**2) - 0.5

   result = f(0.8 + epsilon)
   m = result.dual
   y0 = result.real
   0.8 - y0 / m
   ```

3. On trace le graphe

   ```python run math highlight="1"
   import matplotlib.pyplot as plt
   import numpy as np

   def f(x):
       return np.exp(-x**2) - 0.5

   result = f(0.8 + epsilon)
   m = result.dual
   y0 = result.real
   x1 = 0.8 - y0 / m

   x = np.linspace(0, 1.5, 100)
   t = m * (x - 0.8) + y0
   plt.axhline(0, color="black")
   plt.axvline(0, color="black")
   plt.plot(x, f(x), label="f(x)")
   plt.plot(x, t, label="t(x)")
   plt.scatter(x1, 0, color="red", label=x1)
   plt.legend()
   ```

# Implémentation Python (non-examinable)

L'implémentation des nombres duaux dépasse le cadre de ce cours,
mais nous la mettons à disposition des intéressé·es.
Le code contient des concepts que vous verrez plus tard dans vos études,
mais vous pouvez vous concentrer sur la logique générale.

:::steps

1. On définit un type de données, appelé `Dual`, pour représenter les nombres duaux.
   Il prend en argument la _partie réelle_ et la _partie duale_.
   Par exemple, le nombre dual $1 + 2 \epsilon$ est représenté par `Dual(1, 2)`.

   ```python run
   import dataclasses

   # Dual est un "type de données". Vous reviendrez sur ce concept plus tard dans vos études.
   @dataclasses.dataclass
   class Dual:

       # Stocke la partie réelle, accessible via `self.real`
       real: float
       # Stocke la partie duale, accessible via `self.dual`
       dual: float

       # Explique à Python comment afficher un nombre dual
       def __repr__(self):
           return f"{self.real} + {self.dual} ε"

   # Créons un nombre dual 1 + 2 ε, déclenche __repr__
   Dual(1, 2)
   ```

2. Apprenons à Python à multiplier deux nombres duaux.
   Rappelons que
   $$(a + b\epsilon)(c + d\epsilon) = ac + (ad + bc) \epsilon,$$
   ce qui en particulier implique que $\epsilon^2 = 0$.

   ```python run highlight="11-19"
   import dataclasses

   @dataclasses.dataclass
   class Dual:
       real: float
       dual: float

       def __repr__(self):
           return f"{self.real} + {self.dual} ε"

       def __mul__(self, other):
           # Multiplication d'un nombre dual par un réel
           if isinstance(other, (int, float)):
               return Dual(self.real * other, self.dual * other)
           # Multiplication de deux nombres duaux
           return Dual(
               self.real * other.real, # ac
               self.real * other.dual + self.dual * other.real # ad + bc
           )

   # Testons la multiplication de deux nombres duaux
   epsilon = Dual(0, 1)
   epsilon * epsilon
   ```

   Il faudrait implémenter l'addition (`__add__`), la soustraction (`__sub__`), la division (`__truediv__`) et la puissance (`__pow__`)
   pour que l'arithmétique des nombres duaux soit complète.

3. Apprenons maintenant à Python à calculer le sinus d'un nombre dual.
   Rappelons que
   $$\sin(a + b\epsilon) = \sin(a) + b \cos(a) \epsilon$$

   ```python run highlight="2,20-25"
   import dataclasses
   import math

   @dataclasses.dataclass
   class Dual:
       real: float
       dual: float

       def __repr__(self):
           return f"{self.real} + {self.dual} ε"

       def __mul__(self, other):
           if isinstance(other, (int, float)):
               return Dual(self.real * other, self.dual * other)
           return Dual(
               self.real * other.real,
               self.real * other.dual + self.dual * other.real
           )

   def sin(x):
       # Si x est un nombre réel, on utilise la fonction math.sin
       if isinstance(x, (int, float)):
           return math.sin(x)
       # Sinon, sin(a + b ε) = sin(a) + b cos(a) ε
       return Dual(math.sin(x.real), x.dual * math.cos(x.real))

   # Testons le sinus d'un nombre dual
   x = Dual(math.pi, 1)
   sin(x)
   ```

   Il faut également implémenter les autres fonctions mathématiques usuelles.
