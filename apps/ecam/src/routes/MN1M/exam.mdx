## Séance 1

- Pouvoir utiliser Python comme calculatrice scientifique.
- Utiliser le fait que Python fonctionne avec $15$ chiffres significatifs,
- Savoir si un nombre a une représentation binaire exacte
- Comprendre la vectorisation
- Utiliser le fait que les fonctions de `numpy`, contrairement à `math`, sont vectorisées.

### Exemple de questions

- Écrivez le calcul {tex`\displaystyle \frac{7^3}{3 \sin x }`} en Python
- Quel est le résultat de `3 ** 3`?
- Le nombre $0.4$ est-il stocké de manière exacte dans la mémoire de l'ordinateur?
- Quel sera le résultat du code suivant:

  ```python
  import numpy as np

  x = np.array([1, 2, 3])
  x ** 2
  ```

- Que faut-il changer au code suivant pour qu'il fonctionne?

  ```python
  import math
  import numpy as np

  x = np.array([1, 2, 3])
  math.sqrt(x)
  ```

### Exemples de question
